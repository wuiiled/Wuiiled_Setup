## 💡 如何使用
在下方表格中，**右键点击**对应规则链接，选择 **“复制链接地址”** 填入客户端订阅即可。

### 🛠️ Sing-box 客户端配置示例
在 `config.json` 的 `route.rule_set` 中配置远程规则集（推荐优先使用高效的二进制 `.srs`）：
```json
{
  "tag": "geosite-cn",
  "type": "remote",
  "format": "binary",
  "url": "https://raw.githubusercontent.com/wuiiled/Wuiiled_Setup/singbox/rules/geosite/geosite-cn.srs",
  "download_detour": "direct"
}
```
