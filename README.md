## 💡 如何使用
在下方表格中，**右键点击**对应规则链接，选择 **“复制链接地址”** 填入客户端订阅即可。

### 🛠️ SmartDNS 客户端配置示例
在 `smartdns.conf` 中引入规则集文件：
```conf
domain-set -name geosite-cn -file /etc/smartdns/rules/geosite-cn.txt
```
